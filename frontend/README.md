# Frontend (Astro)

Aplicacion web principal de ITM.

## Comandos

Ejecutar dentro de frontend o desde la raiz con -w frontend.

- npm run dev
- npm run build
- npm run preview
- npm run i18n

## Notas

- El contenido estatico vive en public.
- Las rutas de pagina viven en src/pages.
- Para generar archivos de programa usa npm run generateProgram.
